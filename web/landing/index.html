快速入门

随着 Agentic AI 与多模态的普及，Token 已成为核心数字能源。牛头词元 (NeuToken.ai) 提供与 OpenAI 完全兼容的 REST API，只需修改 Base URL 和 API Key，即可无缝迁移，享受高达 50% 的成本优化。

1. 基础端点 (Base URL)

https://api.neutoken.com/v1

2. 发起第一个请求 (cURL)

使用您在控制台生成的 API Key 替换下方示例中的密钥，发起一次对话请求：

curl https://api.neutoken.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-neutoken-xxxxxxxxxxxxx" \
  -d '{
    "model": "gpt-4o",
    "messages": [{"role": "user", "content": "你好，世界！"}]
  }'

💡 提示：只需更改 model 参数（如改为 deepseek-chat），无需修改任何其他业务代码，即可在同一接口下体验并对比全网不同大模型。

3. 多模态视觉 (Vision)

如果模型支持视觉（如 gpt-4o），你可以直接在 content 数组中传入图片的 Base64 编码或公网 URL：

{
  "model": "gpt-4o",
  "messages": [
    {
      "role": "user",
      "content": [
        {"type": "text", "text": "这张图片里有什么？"},
        {"type": "image_url", "image_url": {"url": "https://example.com/image.jpg"}}
      ]
    }
  ]
}
